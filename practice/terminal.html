Intro To Terminal

Introduction

Hi - My name is Daylen and I took ITD 110 - Web Page Design last year. Some useful commands in Terminal in my opinion
are mkdir, cd, ls. These are the basic commands you'll use to move around in Terminal.

mkdir

When you need to create a new directory you should use mkdir

One example of using mkdir would be

mkdir projects

This would make a directory called "projects". you can also make multiple directpries at once by writing this.

mkdir projects history 911

So if you want to create a new directory, mkdir would be what you need.

cd

If you want to move to a different file or directory when in terminal then you should use cd

An example of using cd would be to say,

cd desktop

You can also move through multiple directories like this,

cd Desktop/projects/history/911/

So when you want to move to a different directory/file you need to use cd
